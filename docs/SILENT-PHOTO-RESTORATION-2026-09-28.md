# 图片静默还原与疑点问答（2026-09-28）

## 本次交付

群里收到图片后，在后台保存图片并排队处理。不发送接收提示、转写全文、资料入口、核验报告或确认指令。后台自动归档图片原文；以后学习者主动开始复习时，优先逐条询问未决疑点。

生产服务切换到 `SourcePhotoService`；旧 `PhotoKnowledgeService` 保留兼容旧资料与回归，旧草稿不会被自动改写或自动确认。

## 四个阶段

| 阶段 | 输入与产物 | 行为 |
| --- | --- | --- |
| 1. OCR① | 图片 → 原始逐页识读 | 独立请求，保留疑字、批注及页号 |
| 2. OCR② | 同一图片 → 第二份逐页识读 | 不传入第一次结果 |
| 3. 合并还原 | 两份 OCR → 按原图段落组织的来源资料 | 模型负责分段、引用行号与比较；程序验证原始行完整覆盖 |
| 4. 联网 + 教材首轮核对 | 原文段落、联网证据、本地 PDF 候选 | 本地检索不调用模型，PDF 候选随联网请求一起核对 |

短内容、单批、无重试时，实际模型请求为 4 次；已通过真实适配器加模拟 SSE 的端到端测试。长内容按批核对，或遇到可恢复错误重试时，请求数会增加，因此“四次”是四个正常阶段，不是费用硬上限。核对沿用可配置的分批、重试和时间预算。

### 原文保真

- 两轮相同的字保留；对应行不同的片段留 `【不清】`。换行无法直接对应时保留 OCR① 与 `【待核对】`，原始两轮识读都可追溯。
- OCR② 独有行不会悄悄丢弃：生成待辨认空位并记录两种读法；不直接认定第二轮正确。
- 合并模型可能生成的扩写只留作候选，不写入原文。核验建议、背景解释、联网引用与原文分别保存。
- 不确定条目仍入来源资料并建立疑点，不因无法核验而整条删除。
- 原文段落上限 200；超过上限或上下文预算时明确失败并保留图片及成功检查点，不截断后伪装成功。

### 教材匹配

PDF 需经现有教材导入流程转为数据库中带 `materialKind: textbook` 的资料，且与图片处于同一资料范围。只在当前范围检索，防止串群或串私聊。候选绑定资料 ID、版本、原文摘录与已有页码；返回结果不能自行编造教材引用。

未导入教材时记录 `not_imported`，仍尝试联网核对。联网不可用时保留原文，记录核对失败，不把服务错误变成学习者问题。后续导入教材后，应用中可点击“重新核对”，只执行核对阶段，沿用 OCR、原文和已保存的个人界定。

## 疑点闭环

| 使用动作 | 结果 |
| --- | --- |
| 群里发图片 | 静默入队；后台处理与自动归档 |
| 成员之间聊天 | 记录本范围上下文，默认不参与 |
| 学习者说“小助手，开始复习” | 有疑点时先问一个，识读疑点优先 |
| 学习者明确回复该疑点消息 | 将回答保存为这条资料的用户界定 |
| 其他成员接话或回答别的话题 | 不作为学习者答案 |
| 回答“暂不确定” | 保留空位，稍后再问 |
| 应用点击“先问我一个”或“随机抽查” | 同一份疑点状态；填写答案后即时显示 |

群聊问答绑定学习者、范围、当前会话、来源版本、疑点版本及机器人实际送达的消息；邀请有效期为 10 分钟。群里使用明确回复或邀请编号，避免将普通成员聊天误存为答案。`/new` 只使旧邀请失效，不删除已归档资料与答案。

用户界定以 `user_defined` 保存，之后会进入资料检索和回答参考。它代表用户对笔记的说明，与机器原文和事实核验分开；不会悄悄覆盖原图，也不会自动升级为已审核标准答案。

2026-10-06 调整：明确 @机器人就是回复请求，不再检查正文关键词；同时 @其他成员也不会拦截机器人。单独 @没有正文时，Agent 简短回应并询问需要什么帮助；明确 @必须有文字回复，模型异常时发送错误提示。明确称呼“小助手，……”／“复习小助手，……”／“AI，……”仍可提问，普通人际聊天继续旁听。已送达疑点的精确回复是专门的回答入口，指定控制命令保留。没有 @的新图片继续静默后台整理；带 @的图片在进入后台任务后也获得 Agent 回复。

## 恢复与存储

- 图片在调用模型前保存到数据文件旁的 `knowledge-assets`，任务与各阶段检查点持久化。模型处理不占用群消息处理器。
- 同一消息去重；后台串行执行图片任务，新图片可以继续入队。
- 重启从最近成功阶段恢复；坏 OCR 检查点会失效并从该轮重新识读；失败可在应用继续处理。
- 任务记录保存错误码、失败阶段，日志保留有长度上限的脱敏 message/stack。所有长输出沿用流式请求。
- 重新核对只更新证据，不复制新的原文版本或覆盖用户界定。
- 来源资料不会自动生成“已学过”“遗忘”或完成复习记录。学习排程仍由原有显式操作触发。
- 完整备份用现有 `runtime:backup` / `runtime:restore`，包括运行数据和图片资产。旧 `knowledge:export` 是资料交换快照，尚不承载新的疑点问答状态，不作为此功能的完整迁移备份。
