# 前端设计方向：研读批注工作台

## 设计任务

为一位在 iPad 上准备考研 333 的学生，把“今天有很多要复习”转变为“现在开始回忆第一个知识点”。页面的唯一主任务是启动主动回忆，不是展示仪表盘数据。

## 视觉系统

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 深墨蓝 | `#10263D` | 左侧工作台、主要动作、结构锚点 |
| 索引蓝 | `#2D6F9F` | 学习状态、链接、掌握度 |
| 雾蓝 | `#DCEAF5` | 当前任务的背景与柔和层次 |
| 纸白 | `#FBFDFF` | 阅读面与作答面 |
| 批注橙 | `#DF6846` | 当前步骤、需要注意的薄弱项 |

- 标题：`Songti SC` / 宋体回退，像教材中的章节标题；只用在有意义的知识点和主句上。
- 正文：`PingFang SC`，保持 iPad 上阅读和输入的清晰度。
- 辅助数据：等宽字体，承载步骤和掌握度，不喧宾夺主。

## 布局与标志元素

```
深墨蓝侧栏       内容区：今日的一句学习命题 + 考试日期
学习原则          ────────────────────────────────────
                 三段回忆轨道：提取 → 组织 → 校准
                 ────────────────────────────────────
                 当前任务（唯一大卡）      易忘清单 / 提示
                 后续任务（轻量行列表）
```

标志元素为“三段回忆轨道”。它不是装饰，而是每一次任务真实遵循的行为顺序：先关资料提取，再组织要点，最后自评校准下一次复习。当前步骤以批注橙标记。

## 自检

- 移除了原页面的奶油色、圆角卡片栅格和泛用 dashboard 视觉。
- 首个知识点拥有唯一的视觉权重，后续任务退为行列表，直接降低“任务过多”的压力。
- 明确保留了键盘焦点、缩减动画与小屏响应式规则。
