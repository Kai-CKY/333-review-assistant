## 1. 产品概述

这是一个围绕“记得住、会输出、知道下一步做什么”的个人考研 333 复习助手。它不做泛聊天机器人，而是将知识点、练习、作答、掌握度和复习时间连接为可追踪闭环。

本期仅建设 Web/PWA 与核心后端。未来的飞书机器人只是同一核心能力的一个渠道入口，不改变本 PRD 的领域模型或接口。

### 1.1 目标

- 根据知识点掌握情况生成少量、可选择的今日复习任务。
- 用填空、选择、关键词提纲和主观题检验“能否主动回忆”。
- 用 FSRS 为每个知识点安排下一次复习，特别处理遗忘内容。
- 对简答/论述题给出结构化、鼓励优先的反馈，并沉淀错题和薄弱点。
- 用进度、完成感和每周复盘帮助持续复习，避免复杂、死板或高压的体验。

### 1.2 非目标

- 本期不接入飞书、微信或其他聊天渠道。
- 本期不做公开题库、社群、排行榜、课程售卖或多人协作。
- 本期不承诺 AI 对主观题给出“官方绝对分数”；AI 输出的是依据指定资料和评分量表的练习反馈。
- 本期不把任意网络内容当作 333 的权威答案。

## 2. 用户研究结论

用户已完成一轮复习，痛点是“背了容易忘”和“难以坚持”。最需要的能力依次是：动态调整计划、记忆检测、简答/论述练习、主观题批改，以及错题和薄弱知识点整理。

体验原则：

1. 每日只给 3–5 个候选任务，允许用户自行选择。
2. 遗忘内容优先在次日或由 FSRS 计算的时间点回顾。
3. 批改先肯定已答对的部分，再指出可操作的问题。
4. 所有 AI 题目和批改尽可能显示对应资料依据；没有依据时明确标记为“练习建议”。
5. 默认不发送侵入式提醒；页面内展示到期任务与可选提醒设置。

- 更细的计划编辑、日历视图、可选 Web 提醒。
- 更丰富的统计图、知识点关联图、错题导出。
- 飞书接入。

## 4. 关键用户流程

### 4.1 每日复习闭环

1. 用户打开首页，系统读取到期复习、近期遗忘点、学习目标和当日可用时长。
2. 系统生成 3–5 个候选任务：到期复习优先，其次是薄弱点，再其次是少量新内容。
3. 用户选择一个任务，完成填空、选择、提纲复述或简答。
4. 系统保存作答，用户确认“忘记 / 模糊 / 记住 / 很轻松”中的实际回忆感受。
5. FSRS 计算下次复习时间，系统更新掌握度、薄弱点和今日进度。
6. 当天未完成的任务允许“顺延、压缩、略过”，不默认强制重排。

### 4.2 主观题批改闭环

1. 用户选择知识点或真题并输入答案。
2. 系统检索该题绑定的参考答案、得分点和资料片段。
3. AI 按固定 JSON 结构给出反馈：总分、分点得分、已覆盖点、遗漏点、结构、考试表达、示范答案、引用依据和置信度。
4. 若证据不足或置信度低，页面明确提示“仅供练习参考”，不自动提高/降低正式掌握度。
5. 用户确认自己的回忆等级后，系统更新 FSRS 与薄弱点记录。

## 5. 功能需求

### 5.1 学习档案

- 必填：考试日期、报考院校/专业、每日可用学习时长。
- 可选：每周复盘日、提醒开关、鼓励风格、每日最大任务数。
- 默认值：任务数 3 个；不推送提醒；批改风格为“先鼓励，再指出问题”。

### 5.2 知识点与资料

- 知识点采用 `学科 → 章节 → 知识点` 三级结构。
- 每个知识点至少包含：标题、关键词、简要提纲、适用题型、资料来源、状态。
- 资料来源至少可标记：教材、个人笔记、课程、真题、人工整理。
- AI 生成的题目、答案和反馈必须保存提示词/模型版本、知识点和资料引用，便于追溯与修订。

#### PDF 解析决策

- P0 采用 **MinerU 本地 `pipeline` 后端**，默认中文识别；原始 PDF 与解析得到的 Markdown、结构化 JSON、页码/坐标映射均保存在本机。
- 解析结果必须保留到原 PDF 的页码与块级定位，供题目、批改和用户查看依据。
- 建立 `DocumentParser` 抽象层，不让任何业务逻辑直接依赖 MinerU 输出格式。
- 若首批样本出现中文 OCR、阅读顺序或表格结构明显错误，按“单页回退”接入 PaddleOCR 的 PP-StructureV3 / PaddleOCR-VL；不因个别失败页整体更换存量资料。
- 每份资料导入后状态为“待审核”，审核通过后才可作为 AI 出题和批改的权威依据。

### 5.3 今日任务

- 首页展示一个总进度条，以及“今日可选任务”列表。
- 每项显示预计时长、任务类型、关联知识点、到期原因和完成状态。
- 每日默认最大展示 5 项；更多任务置于“待处理”，不直接压迫用户。
- 未完成任务的操作：`顺延`、`压缩为 5 分钟版本`、`略过并说明原因`。

### 5.4 练习与自评

- 填空：支持关键词和短语答案，展示答案及简短解释。
- 选择：单选/多选，答后展示正确项和知识点解释。
- 提纲：显示题干，用户输入关键词；P0 允许 AI 按要点覆盖度反馈。
- 简答/论述：文本编辑器、字数提示、提交后异步等待批改。
- 每种练习结束必须提供：`忘记`、`模糊`、`记住`、`很轻松`。AI 可推荐，但由用户最终确认。

### 5.5 掌握度、错题和调度

- FSRS 是复习日期的唯一调度器；调度输入为用户确认的回忆等级和复习日志。
- 掌握度面板展示：到期、易遗忘、答题错误、近期练过、稳定掌握。
- 主观题反馈中的遗漏得分点自动作为“待强化点”，但不删除原有学习记录。
- 错题可标记原因：知识点遗忘、审题偏差、结构问题、表达问题、粗心、其他。

### 5.6 周复盘

- 展示：完成任务数、复习时长、练习正确率、遗忘次数、薄弱知识点变化。
- 输出三条以内下周建议，例如“优先复习教育心理学的迁移理论与学习动机”。
- 允许用户写一句本周感受；该内容仅用于生成个人化建议，不参与评分。

## 7. 领域与数据规则

- PostgreSQL 是唯一事实来源；模型对话记忆不能直接充当成绩、计划或调度记录。
- `review_state` 保存 FSRS 卡片状态和 `due_at`；`review_log` 永久保留每次评分事件。
- `answer_attempt` 保存原始主观题答案；`answer_feedback` 保存结构化批改版本。
- `plan_item` 为计划快照，允许完成、顺延、压缩或略过；不篡改历史任务。
- 每个 AI 输出都必须关联 `knowledge_point_id`、`source_chunk_ids`、`prompt_version` 和 `model_version`。

## 8. AI 与资料安全要求

- 只对用户明确上传或人工录入的私有资料建立知识库；不上传或分发无授权资料。
- 题目生成和批改优先引用绑定资料；没有足够来源时拒绝输出“权威标准答案”。
- AI 输出使用结构化 schema 校验，失败时进入人工重试/降级提示。
- 用户答案、笔记和 API 密钥不写入日志；生产环境的密钥通过部署环境注入。
- 初期仅允许单用户访问，但表结构、查询和存储必须按 `user_id` 隔离。

## 8.1 已确认产品决策

| 决策项 | 已确认方案 |
|---|---|
| 用户范围 | 单用户体验；从数据库层面保留多用户隔离 |
| 客户端 | 手机优先 Web/PWA，并优先适配 iPad Safari；长主观题在 iPad/电脑均可完成 |
| 部署 | 第一阶段运行在本机，所有原始资料与数据库本地保存 |
| 资料来源 | 用户提供的 PDF，解析后人工审核再入库 |
| 批改标准 | 通用 333 框架；后续可为目标院校新增独立评分量表 |
| 模型 | 使用国产 API；后端通过 OpenAI 兼容接口抽象供应商，避免绑定单一厂商 |
| 考试日期 | 暂定为 **2026-12-20**，标记为“预计”；官方发布 2027 研考时间后必须可一键更新 |

## 8.2 首批人工审核语料：具体工作说明

这里的“人工审核/录入 20–50 个知识点”不是要求手工抄录整本书，而是先建立一套可验证的金标准小语料。它解决两个问题：一是检验 PDF 解析是否可靠，二是让 AI 批改有可追溯的得分依据。

建议首批建立 **24–40 个高频知识点**，四门科目尽量均衡。每个知识点审核以下内容：

1. **定位**：学科、章节、原 PDF 文件名与页码范围。
2. **核心提纲**：3–8 个关键词与一段简短结构化答案。
3. **评分量表**：简答题的核心得分点、每点分值/权重、常见遗漏或混淆点。
4. **练习种子**：至少 1 道填空、1 道选择、1 道关键词提纲题；其中高频点再增加 1 道简答题。
5. **审核状态**：`draft`、`approved`、`rejected`；仅 `approved` 可被模型检索为依据。

这批语料会成为自动化评测集：每次修改解析器、提示词或模型，都用同一批题检查阅读顺序、引用页码、题目正确性和主观题得分点覆盖率。完成这一小批样本后，再批量导入全量 PDF，能够显著降低“解析错资料导致 AI 一本正经地教错”的风险。

## 9. 验收与测试

### 9.1 P0 端到端验收

1. 导入至少 20 个已审核知识点和 40 道练习后，用户能在首页得到不超过 5 个候选任务。
2. 用户完成一次填空并选择“忘记”后，系统新增复习日志、更新状态，并安排后续复习。
3. 用户提交一题简答后，系统返回符合 schema 的分点反馈；结果中显示至少一个资料依据或“依据不足”提示。
4. 从薄弱点页发起练习后，完成记录能在首页、知识点页和周复盘中一致出现。
5. 断网重试、重复提交和异步批改失败不能产生重复复习日志或重复扣分。

### 9.2 自动化测试范围

- 单元测试：FSRS 评分映射、计划优先级、掌握度计算、任务状态转换。
- 集成测试：API 与 PostgreSQL、任务队列、AI schema 校验。
- 端到端测试：建档 → 今日任务 → 填空 → 自评 → 下次复习 → 周复盘。
- 人工评测：使用固定 333 样题集检查 AI 出题和批改是否与人工评分量表一致。
