# 云端迁移准备

## 当前数据路径

私聊明确完成汇报 → StudyService.recordTaskCompletion → LocalRepository.taskCompletionLogs → GET /api/dashboard → 网页“最近完成”。群聊自然语言目前只保存独立会话上下文，并不会自动进入学习记录。群历史补录使用相同 StudyService、以来源 message_id 去重，保留发送者、群、发送时间和补录时间，保存成功后才发确认。

日期使用 Asia/Shanghai。自报数量不等于复习闭环数量，不改变掌握度、自评或排程。网页在页面载入及本页完成操作后请求 dashboard，尚无推送或定时刷新；飞书写入后刷新网页即可看到。

## 已准备

- DATA_FILE 指定数据文件路径，可用于持久卷和隔离测试环境。
- JSON 更新先写临时文件，再原子替换，减少关机造成半个文件的风险。
- npm run test:integration 验证分页/缺权限、发送者校验、保存后确认、重复补录去重、确认失败后重试、真实 HTTP 页面与 dashboard、服务重启后数据保留、模型失败及上海日期边界。
- 所有自动测试使用临时文件与模拟飞书，不发送真人消息、不调用付费模型。

## 上云前仍需完成

- 当前 JSON 存储只支持单进程；进程内队列不能防止多实例覆盖，原子替换也不能解决多实例一致性。多实例前迁移至事务数据库并增加唯一索引。
- DATA_FILE 放在持久卷上并配置备份与恢复演练；不能留在容器临时层。
- HTTP API 当前没有鉴权，禁止直接公开到互联网；补齐登录、访问控制、请求限制、HTTPS 和密钥管理后再发布。
- 增加持久的群消息游标、离线补读、消息收件箱与回执发件箱；目前历史补录是人工选定消息，不是启动自动扫群。
- 配置长连接运行环境、重启策略、优雅关闭、健康监控；确认同一应用的多个连接不会争抢事件。
- 图片知识已具备原图存储、双次识读、核验、确认保存、修订和范围内查询；真实整页搜索仍出现失败，识读/引用质量需要继续改进。知识快照可随Git迁移，但不会自动覆盖或同步云端运行数据，见[存储与云端修改](KNOWLEDGE-STORAGE-AND-CLOUD.md)。

尚未部署到云，也未宣称已具备生产上线条件。
