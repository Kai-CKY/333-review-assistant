# 羊羊学习者与系统管理员 Agent Prompt

运行时 Prompt 的唯一实现位于 `apps/api/src/agent/prompts.js`，当前版本为 `identity-aware-v3`。真实身份由 `FEISHU_LEARNER_OPEN_ID` / `FEISHU_OWNER_OPEN_ID` 绑定，不能从昵称或对话猜测。管理员采用独立提示词，只读羊羊的数据，不进入作答、自评和完成自报路由；未绑定私聊不获得学习数据。群内显示绑定角色且不注入私聊记录。

以下分层适用于学习者羊羊：

1. **基础身份与档案**：只服务李羊羊，目标为 2027 年考研 333；已知其完成一轮复习、容易遗忘且难以坚持。目标院校、专业和每日可用时长仍是未知，不允许模型补猜。
2. **只读意图层**：仅允许 `chat`、查看今日/进度/薄弱点/最近完成、建议任务、提示、帮助和歧义澄清。模型输出必须通过严格 JSON 校验，不能产生任何写操作；`chat.reply` 可直接发送，避免再调用一次模型。
3. **自然对话层**：负责知识解释、追问、学习状态沟通和简短陪伴。服务器只提供必要的今日任务、进度、薄弱点与当前会话摘要。
4. **答题陪练层**：给渐进提示，默认不直接代写完整答案；提示和问题不进入答题记录。
5. **作答反馈层**：只输出“亮点 / 可补充 / 下一步”三行结构性建议。没有人工审核答案时，不判定事实正确性、不打分、不参与排程。

## 不变量

- 身份门禁先于任何模型调用：只接受配置中绑定账号的私聊。
- 模型不拥有提交答案、开始任务、取消、自评、改档案或改复习计划的权限。
- 明确的第一人称完成汇报由服务器规则直接写入独立复盘备案；模型不参与识别或写入，也不能把自报当作已核验学习效果。
- 只有服务器工具明确成功，回复才能宣称数据已写入。
- 当前演示知识点必须标成演示资料，不能推断为李羊羊的真实掌握情况。
- 不向模型提供 `.env.local`、API Key、App Secret 或内部身份标识；本地短期对话历史会先脱敏再使用。
- 自然语言中的模糊自评不映射四档，必须由李羊羊明确选择。
- 计划、否定、疑问、假设、未来时态和第三人称完成陈述不得自动备案；消息 ID 用于幂等，误记可撤销。

## 答题状态优先级

- `答案：……`：确定性提交。
- `问：……`、请求提示、表示没懂：进入陪练，不保存。
- 普通问候、感谢、焦虑或疲惫表达：自然对话，不保存。
- `我今天完成了……`、`今天任务完成情况：……` 或 `/记录 ……`：在模型调用前写入独立的最近完成备案，不作为当前题答案，也不改变排程。
- 短问句或难以判断的内容：弹出确认卡，确认前不保存。
- 明显陈述性回答：作为当前题目的答案。

每次作答反馈都会以持久化任务保存：`feedback_job` 和关联 `answer_feedback` 记录相同的状态、幂等键、模型版本、Prompt 版本、资料快照与错误码，方便之后审计、恢复和升级。
