# PDF 解析接入验证（2026-09-26）

## 已验证

- 本地应用回归：72 项 Node 测试通过，包括 PDF 上传登录/角色/来源校验、重复上传、范围隔离、失败重试、重启中断、原件快照恢复和群聊确认。
- Python：3 项测试通过，覆盖页码/表格/坐标转换、空结果、损坏 PDF、加密 PDF、超页数拒绝。
- 实际引擎：MinerU 3.4.5 pipeline，CPU。本地 Python 3.12、Torch 2.14.0。两页合成中文 PDF（第一页有文字层、第二页仅图片）中的中文名称、频次、年份及各页不同的随机校验码均正确，返回 6 个文字块和原页码/坐标。
- 真实应用链路：隔离的临时数据库、测试账号，通过 HTTP 上传相同 PDF → 私有 MinerU 服务解析 → 预览 → 显式确认 → 知识索引查询。确认前条目数为 0，确认后为 6；原 PDF 下载字节一致。一次热缓存调用耗时 18.5 秒，不代表生产服务器性能承诺。
- 镜像内可复用的 `smoke.py`：文字页与扫描页校验码均通过。测试只用合成文件，不读取真实知识库或调用付费 LLM。

## 实测修复

- MinerU 3.4.5 pipeline 的 OCR 实现引用 `six`，但包依赖没有声明；镜像已补齐 `six==1.17.0`。
- 改用固定版本的 Python API，在独立子进程解析，避免 CLI 临时 HTTP 服务的额外生命周期管理。
- 原文件不覆盖，保留结构化结果；空白/未识读页可见。图片/表格无法还原时明确提示核对。
