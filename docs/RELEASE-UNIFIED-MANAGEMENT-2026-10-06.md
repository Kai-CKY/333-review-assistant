# 管理费用、操作与复习记录发布

用户授权本次开发、提交和 SSH 发布。当前功能分支为 `codex/unified-management-20261006`，基线为正式提交 `7367b72`。发布使用通过 CI 的确切提交及对应镜像。运行数据和凭据不进入 Git。

## 功能

- 管理员工作台新增用量与费用、管理操作、复习记录。学习者新增月历和完整逾期列表。
- 每次真实模型请求记录用途、步骤、任务、环境、Key 别名、原始 usage 和结果。未知用量保持未知。缓存包含在输入中，推理包含在输出中。
- 价目保存独立版本。历史请求保留原价目。官方账单通过文件预览后导入，不再次计入模型账本。
- 预算默认未设置。管理员可以设置每日和每月金额。80% 和 100% 产生持久告警，超额继续调用。
- 表情由原回复请求选择。页面不单列表情费用。表情失败保留文字回复，重复事件不重复添加表情。
- 管理发送先核对目标群与原生 @。稳定请求 ID 防止重复发送。结果未知时只核实回执，不自动重发。
- 外部操作可补记实际时间、摘要和证据。只有明确填写的公开结果进入同群上下文。管理员私有摘要不进入群。
- 自评保存真实时间和精确作答关联。历史缺失时间保持为空。打开练习、模型反馈和管理操作不算复习完成。

## 验证

本地完整回归为 218 项。检索回归使用 1007 个合成知识点，Top 5 命中检查及 3 个负例通过。新增用例覆盖断流、重试、解析失败、账本写入故障、预算、管理发送去重、上下文隔离、权限和原生恢复。

使用独立本地库检查桌面及 390px 页面。费用页预算、分页、搜索、详情、价目和账单预览正常。复习及操作页面无脚本错误。自动化浏览器的下载命令返回 `Download was canceled`。CSV 接口另行校验响应与文件内容，不将该浏览器命令记为成功。

飞书表情标识按照[官方表情文档](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/reference/im-v1/message-reaction/emojis-introduce)核对。发布检查不代发学习消息、不代选自评。真实群测需要管理者本人发送消息；未执行时如实记为未执行。

## 数据与恢复

迁移 `2026100601` 新增六个独立管理／费用表，并为作答、自评增加精确时间及关联列。迁移可重复运行。普通学习写入不重建独立账本。

`runtime:backup` 对 relational-v1 保存原生 SQLite 快照及附件清单。`runtime:restore` 校验哈希、完整性和外键。恢复写入新目录，保留账本、操作和价目。不能把仅含领域数据的 JSON 备份当作完整新库备份。

发布前保存旧提交、镜像、Compose 和停机后的完整运行目录。在隔离数据副本上验证升级、原生备份恢复及持久化。正式发布只替换代码和镜像。不得用测试数据或配置覆盖正式目录。

旧应用可以读取新增列，但旧备份脚本不包含独立账本。回滚前先保存完整新库。优先恢复旧代码和镜像，并保留经过兼容检查的新库。只有确认没有新增业务写入时才可以恢复停机快照。

## 管理客户端与本地调用

`scripts/management-client.mjs` 通过管理员 Web 认证访问管理接口。凭据文件默认为 Git 忽略的 `.data/management-login.json`，格式为 `{url,username,password}`。URL 使用 HTTPS 或本机 SSH 隧道。发送与补记的输入文件必须保留相同 requestId。

独立本地模型脚本默认把观测记录保存在 `.data/model-usage.sqlite`，环境为 local。可以用 MODEL_USAGE_FILE 指定独立账本。生产、测试和本地账本分别保存；“全部环境”只汇总当前数据库内的记录，不代表方舟整个账户。官方账单用于核对共享 Key 的实际扣款。历史缺少 usage 的调用不补造用量。

## 执行顺序

1. 提交功能分支并推送 GitHub。
2. 等待该提交的 CI、镜像构建与部署 smoke 通过。
3. 下载镜像并检查 SHA256。旧服务器不构建镜像。
4. 在独立测试库验证迁移、登录、模型 usage、接口与重启。
5. 停止正式容器。保存一致性运行目录和回滚资料。下载备份到本机。
6. 快进正式 main。使用同一提交镜像执行 `docker compose up -d --no-build`。
7. 检查容器、健康、运行版本、数据库、管理查询和飞书连接。保留测试飞书关闭。
8. 保存实际结果和备份路径。向用户汇报上线结果。
